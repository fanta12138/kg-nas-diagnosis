## C. 数值一致性审计（本轮新增）

换体裁压缩篇幅时逐节改写，**用脚本核对数字无静默丢失**：

```bash
python D:/autopaper/adbench/numsnap.py save G:/submission_KBS/sections/_draft_v2 before.json
python D:/autopaper/adbench/numsnap.py diff before.json G:/submission_KBS/sections/_draft_v2
```

脚本提取每节所有数字 token 并做多重集差分。**所有被压缩掉的数字均已确认属于以下三类之一**：
①被删除的重复论述；②表格中被 caption 明确概括的逐骨架数值（全表随代码释放）；
③引用键中的年份数字。
