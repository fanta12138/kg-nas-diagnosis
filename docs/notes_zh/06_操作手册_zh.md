## 一、安全约定（不可违反）

1. **改动前备份**：任何 `.tex` / `.bib` 改动前带时间戳备份
   ```bash
   cp main_springer.tex "main_springer.tex.$(date +%Y%m%d_%H%M%S).bak"
   ```
2. **批量的文字改动必须走带断言的补丁脚本**（`apply_patches.py`），不要用 `sed`/正则
3. **数据不可伪造**：结论与数据冲突时改结论，不改数据
4. **论文数字唯一基准**：`D:/autopaper/` 下的实验记录

## 二、编译

```bash
cd /g/submission_KBS

# MVA 投稿版（Springer, sn-jnl, [iicol] 双栏）★
/d/texlive/2026/bin/windows/pdflatex -interaction=nonstopmode main_springer.tex   # 跑两遍以稳定交叉引用

# Elsevier 备查版
/d/texlive/2026/bin/windows/pdflatex -interaction=nonstopmode main.tex

# 补充材料
/d/texlive/2026/bin/windows/pdflatex -interaction=nonstopmode \
    -output-directory=supplementary supplementary/supplementary.tex
```

**验收标准**（每次改完必查）：
```bash
grep -o 'Output written on main_springer.pdf ([0-9]* pages' main_springer.log | tail -1
grep -c '^!' main_springer.log                       # errors，期望 0
grep -c 'Undefined control sequence' main_springer.log  # 期望 0
```

> ⚠️ **编译耗时较长**（1200 dpi 图片），建议用 `run_in_background: true` 后台执行。
> Bash 工具默认 120 秒超时，`sleep` 超过 100 秒会被 SIGTERM。

```

├── README.md                  ← 入口索引
```

## 五、实验环境（`D:/autopaper/`）

### 硬件与约束
- **GPU**：RTX 3090 24GB
- ⚠️ **单训练进程占 7.6GB** → **必须顺序执行**。5 路并行因显存颠簸会**慢 55 倍**
  （实测：6M/wood 单进程 4.3 min vs 5 路并行 235 min）
- 单类目 500-epoch 训练约 **3–5 分钟**

### 网络与权重
- `huggingface.co` 与 `github.com` **均被网络拦截**（502）→ 必须设
  `HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1`
- 本地已缓存 14 个 timm 骨架权重（resnet/effnet/mobilenet/convnext/vit/deit/swin/mobileone）
- **无 wide_resnet50** → 依赖它的实现（如标准 PatchCore）无法离线运行

### 实验目录
| 目录 | 内容 |
|---|---|
| `unsupervised_nas/` | 主项目（模型、训练脚本、历史实验） |
| `capacity_experiment/` | 参数量扫描（架构轴） |
| `paradigm_select/` | 范式选择（打分规则轴） |
| `fusion_policy/` | 打分策略搜索 ⭐ |
| `policy_select/` | 无标签策略选择 |
| `proxy_diag/` | 代理可靠性诊断 |

### 代码复用要点
- **训练函数**：`unsupervised_nas/scripts/p2_rd_train.py` 的 `train_category()`
  —— **自带断点续跑**（已有 `final_evaluation.json` 会跳过）
- **导入方式**：`scripts/` 不是包，须用
  ```python
  import importlib.util
  spec = importlib.util.spec_from_file_location('p2', '.../scripts/p2_rd_train.py')
  mod = importlib.util.module_from_spec(spec); spec.loader.exec_module(mod)
  ```
- **教师模型**：`experiments/stage1/best_teacher.pth`（ResNet-18，150MB）

## 六、已知陷阱

| 陷阱 | 现象 | 对策 |
|---|---|---|
| HF 联网 | 搜索脚本未设离线 → 卡在权重下载重试（3 trial 卡 10 分钟） | 设 `HF_HUB_OFFLINE=1` |
| 后台进程被回收 | `(cmd &)` 起的进程在命令结束时全部消失 | 用 `run_in_background: true` 的受管任务 |
| Bash 超时 | `sleep 180` 被 SIGTERM | 采样 `sleep` ≤100 秒 |
| 补丁误报 | `apply_patches.py` 报"旧串仍在"，但文件其实已正确写入 | 当**替换串包含查找串**时会发生；手工核对实际内容 |
| 逐字比对漏检 | `45-configuration` 与 `45 configuration` 视为不同 | 比对前**去连字符**归一化 |
| 显存颠簸 | 并行训练极慢 | **顺序执行** |
| 预览锁文件 | 预览面板会独占文件，导致写入 `PermissionError` | 改文件前确认预览已关闭 |
